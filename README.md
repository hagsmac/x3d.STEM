# Manifold of Emotion, in X3D

Live: https://hagsmac.github.io/x3d.STEM/

An emotional field as a Riemannian surface (g = λ² (dx² + dz²), curvature K = −Δ ln λ / λ², geodesics as light), recreated as one ISO-standard X3D 4.0 scene (`scenes/manifold.x3d`) and drawn by X_ITE 16.5.1. Source, builder, witnesses and evidence: `studies/manifold` on the main branch. Debrief: `docs/DEBRIEF.md`. The CJK label font is a subset of Noto Sans SC under the SIL Open Font License (`src/FONT-LICENSE.txt`).
